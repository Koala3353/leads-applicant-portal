# Email images

GIFs used by the results emails (the tracker's "Results Email Appscript": Combined Email Sender). They are hosted here,
on GitHub Pages, so mail apps show them inside the email (like the payment emails' imgur images) instead of as
attachments. URL: https://koala3353.github.io/leads-applicant-portal/mail/<name>.gif

eye_g / eye_r / nosig: the three CCTV monitors · rec: the REC dot · peek: the closing eye ·
tape1: "I.R.I.S. IS WATCHING /// RESULTS ARE IN" · tape2: "CAMP JAN 29-31 /// WHERE: REDACTED /// WE SEE YOU HESITATING"

Renaming or deleting a file here breaks the image in emails that were already sent.
